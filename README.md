# C++ Basic Programs

Beginner C++ programs built in Visual Studio (one solution, four projects):

1. **Calculator**: simple calculator (+, -, *, /)
2. **ArraySumAverage**: sum and average of array elements
3. **PrimeCheck**: checks whether a number is prime
4. **ReverseNumber**: reverses a given number

## How to run
1. Open `CppBasicPrograms.sln` in Visual Studio.
2. Right-click the project you want, then **Set as Startup Project**.
3. Press **Ctrl+F5**.
